# 🎓 SIAKAD PORTAL MVP
**Perencanaan dan Pembangunan Portal Akademik Mahasiswa Berbasis Web dengan Fitur Pengelolaan KRS, Presensi Real-Time, dan Evaluasi Nilai**

Proyek Mata Kuliah **Manajemen Proyek TI** — Pengembangan *Minimum Viable Product* (MVP) menggunakan metodologi **Agile Scrum (3 Sprint)**.

## ✨ Fitur Inti (MVP)
1. **Autentikasi & Otorisasi Multi-Role:** Login terpisah untuk Admin Akademik, Dosen Wali/Pengampu, dan Mahasiswa.
2. **Manajemen Data Master Akademik (Admin):** Tambah, lihat, dan hapus daftar mata kuliah beserta SKS dan jadwalnya.
3. **Pengelolaan KRS (Mahasiswa & Dosen):** Pengajuan mata kuliah oleh mahasiswa dan validasi persetujuan (*Disetujui/Ditolak*) oleh Dosen Wali.
4. **Presensi Real-Time (Dosen & Mahasiswa):** Pembukaan/penutupan sesi presensi kelas secara langsung (*real-time*) oleh dosen dan tombol hadir interaktif bagi mahasiswa.
5. **Evaluasi Nilai Otomatis & KHS (Dosen & Mahasiswa):** Input nilai Tugas (30%), UTS (30%), dan UAS (40%) dengan kalkulasi otomatis Nilai Akhir dan Huruf Mutu (A/B/C/D/E).
